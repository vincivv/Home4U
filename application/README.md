# Home4U Application

This folder contains the product source code for Home4U.

- `backend/`: FastAPI API, SQLAlchemy models, Alembic migrations, auth, scoring, recommendation services, and smoke tests.
- `frontend/`: React/Vite client, route-level pages, reusable UI components, API services, and frontend tests.
- `deployment/`: nginx, systemd, and deployment helper scripts used by the original production deployment.
- `credentials/`: placeholder for deployment credentials.

Use the root [README.md](../README.md) for the portfolio overview and local setup commands.
